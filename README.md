# Анаглиф-Тетрис

Дихоптический тетрис для красно-синих очков: падающая фигура видна только слабому глазу, уложенные блоки — только сильному. Чтобы играть, глазам приходится работать вместе.

## Как запустить
Открой `index.html` в браузере (на весь экран, F11). Нужен чёрный фон и очки: красный фильтр — левый глаз, синий — правый.

## Настройки
- **Слабый глаз** — по умолчанию правый (синий фильтр).
- **Яркость для сильного глаза** — начни с ~30% и повышай по мере привыкания.
- **Автобаланс** — +5% яркости сильному глазу за каждые 10 линий.
- **Длительность сеанса** — 5–30 минут, по умолчанию 15.
- Пурпурная рамка видна обоим глазам и помогает удерживать слияние.

Настройки и история сеансов хранятся в браузере (localStorage).

## Управление
← → двигать · ↑ повернуть · ↓ ускорить · Пробел уронить · P / Esc пауза. На телефоне — кнопки под полем.

## Важно
Это тренажёр, а не лечение. Рецидив экзотропии и размытость вблизи стоит показать офтальмологу/ортоптисту.
